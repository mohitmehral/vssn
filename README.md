# 🕉️ Sanatan Dharma

A modern, animated, multilingual awareness website about **Sanatan Dharma** —
its civilization, scriptures and living concepts — presented for the curious,
educated mind. High-class design blending the **ancient and the modern**.

Built with **Astro + React + Tailwind + Framer Motion**, and deployed as a
static **GitHub Pages** site.

**Live (once deployed):** `https://mohitmehral.github.io/sanatan/`

---

## ✨ What's inside

- **Animated hero** with a rotating sacred-geometry mandala and floating light motes (VFX feel, pure SVG + Framer Motion — light and fast).
- **Core concepts** — Vedas, Karma, Dharma, Atman & Brahman, Yoga, Moksha — as scroll-revealed cards.
- **Civilization timeline** — from Neolithic Mehrgarh through the Indus–Sarasvati civilization, the Vedic and Upanishadic ages, the classical flourishing, and the living tradition. **Each era cites its evidence** (archaeology, texts, epigraphy).
- **Living calendar / events**
  - **Festivals & tithis** (Ekadashi, Poornima, Amavasya, Diwali, Holi, Navratri, Janmashtami, Maha Shivratri). **Hover any card** to read the meaning and its **authentic scriptural source** (e.g. Ekadashi → Padma Purana).
  - **Our Trust Events** — an **auto-scrolling** photo showcase (pauses on hover) that always shows the **latest-dated images** from `docs/events/`.
- **10 languages** — English + Hindi (primary), plus Chinese, Spanish, Arabic (RTL), Bengali, Portuguese, Russian, French, Japanese. Per-locale URLs (`/en/`, `/hi/`, …) with a language switcher.
- **SEO** — per-locale `<title>`/meta, canonical + `hreflang` alternates, Open Graph + Twitter cards, JSON-LD structured data, `sitemap-index.xml`, `robots.txt`.

## 🚀 Getting started

```bash
npm install
npm run dev        # local dev at http://localhost:4321/sanatan/
npm run build      # production build into dist/
npm run preview    # preview the production build
```

> The site is configured with a base path of `/sanatan`, so local URLs include
> it, e.g. `http://localhost:4321/sanatan/en`.

## 🖼️ Adding trust-event photos (no code needed)

`docs/events/` is the **single source of truth** for event photos.

1. Add an image to **`docs/events/`** using this name format:

   ```
   YYYY-MM-DD_short-title.ext        (ext = jpg | jpeg | png | webp)
   ```

   e.g. `2026-08-15_annadanam-seva.png` → caption **"Annadanam Seva"**.

2. Commit and push. The GitHub Action rebuilds and the newest images appear
   first automatically. (Locally, just re-run `npm run build` / `npm run dev`.)

A `prebuild` step (`scripts/sync-events.mjs`) copies these into
`public/events/` so they publish with the site. The three sample PNGs were
generated by `scripts/gen-placeholders.mjs` — delete them once you add real
photos.

## 🗓️ Updating festival dates

Festival dates follow the lunisolar Panchang and shift each year. Edit
`src/data/festivals.ts` and refresh the `nextDate` values from a reliable
Panchang each year. Each festival keeps a `source` field citing the scripture
its meaning is drawn from — please keep these accurate.

---

## 🌍 Adding or editing translations

- UI strings live in `src/i18n/ui/<locale>.ts`. `en.ts` defines the schema
  (TypeScript enforces that every locale has every key).
- Long-form content (timeline eras, festivals) lives in `src/data/*.ts` as
  `{ en, hi, … }` maps and falls back to English when a language is missing.
- To add a language: add its code to `locales` in `src/i18n/config.ts` and
  `astro.config.mjs`, add metadata in `localeMeta`, and create
  `src/i18n/ui/<code>.ts`.

## 📦 Deployment (GitHub Pages)

Deployment is automated via `.github/workflows/deploy.yml`:

1. Create a repo named **`sanatan`** and push this project to its `main` branch.
2. In the repo: **Settings → Pages → Build and deployment → Source = GitHub Actions**.
3. Every push to `main` builds and deploys to
   `https://mohitmehral.github.io/sanatan/`.

**Custom domain?** Set the workflow env `SITE_URL` to your domain and
`BASE_PATH` to `/` (empty base), add a `CNAME` file in `public/`, and update
`robots.txt`.
